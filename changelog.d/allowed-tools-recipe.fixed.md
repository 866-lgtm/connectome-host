- Recipes now validate and forward `agent.allowedTools` (`"all"` or an array of exact tool names), preserving omitted-field defaults and explicit empty lists. Spawned and forked subagents inherit the caller's tool restriction; explicit spawn lists can only narrow it, with `subagent--return` always included. This configures Agent Framework tool visibility; dispatch enforcement remains the framework's responsibility.

- At maximum spawn depth, retain permitted utility names alongside the collapsed `utils` tool. Explicit lists must name both `utils` and each permitted utility. Own-name utility enforcement requires the Framework release from https://github.com/anima-research/agent-framework/pull/220; on Framework 0.22.1, permitting `utils` still permits every utility. This Host correction remains compatible with either Framework release.

- **Existing recipes with `agent.allowedTools`:** the configured value now restricts the resident instead of being ignored with a startup warning. Check existing lists when upgrading. Recipes that omit the field retain their previous default.

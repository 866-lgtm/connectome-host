- **Operators with links inside a workspace mount:** the web UI's `/files/` route no longer serves a link in a mount, even one to another file in the same mount, unless the mount sets `followSymlinks`, and answers 403 for it instead. Open the file by its own path, or set `followSymlinks` on the mount. Unchanged: a mount with `followSymlinks` still follows a link that stays inside it, and a file opened by its own path is served as before.

- A server deployed with `mcpl_deploy` now gets the environment every boot-loaded server gets. That includes the refusal-reaction baseline, `DISCORD_SUPPRESSED_REACTIONS_BASELINE`, as a default its own env can override, which a deployed Discord adapter used to start without.
- `mcpl_deploy` judges each field as given, and refuses a wrong kind with nothing saved, where it used to drop or coerce it: an `env` given as text, a number or true/false, `args` that weren't a list, a `toolPrefix`, `token` or `access` that wasn't text, a `reconnect` that wasn't true or false, or a tool or feature-set list given as text all vanished, and a `null` arg was saved as `"null"`. A field left out, `null`, `""` for text or `[]` for a list is unspecified, as strict function calling sends it, so an empty `toolPrefix` is no longer saved for the framework to keep in place of its default prefix. Numbers and true/false in a list are saved as their text. The id `__proto__` is refused: JavaScript reads it as an object's prototype, so its entry was never saved, though the deploy said it was.
- Saving `mcpl-servers.agent.json` keeps the root's keys besides `mcplServers`, such as an entry under a misspelled key, which every save used to drop.
- `mcpl_unload` reads the overlay before it disconnects, so a file the boot would stop on refuses the unload with the server still loaded. It disconnects only a server that's listed. An id the overlay alone names has its entry removed, or its tombstone kept, with a receipt saying it wasn't loaded in this session. A disconnect that fails leaves the overlay as it was, and says so. Deploys, restarts and unloads of one server run one at a time, in the order they're called, so a deploy made while an unload disconnects runs after it and keeps its entry. A session-only unload says what the next host start loads, read from the overlay: a tombstone, the agent's entry, the operator's definition, or nothing. A tombstone for an id the operator defines says how that definition comes back.
- `mcpl_list` no longer labels a recipe server named like an inherited key, such as `constructor`, as a file server.

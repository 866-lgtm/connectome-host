- An `instructions-unavailable` ops alert when the instructions module injects nothing, whatever the reason: no workspace, an unknown mount, a missing or unreadable file, or a file that is itself a link. It names the reason and, for a link, the remedy: put the file itself at that path. It reaches the TUI, the web UI's alert strip, `failures.log`, the ops webhook and, at the `status` tier, the notices module's status channels, and `instructions-unavailable-clear` stands it down once the file loads again. Before, an agent running without its instructions showed only as a log line. It's raised once per reason, under the resident agent's name.

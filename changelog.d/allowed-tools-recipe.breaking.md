- **Recipe authors whose recipes set `agent.allowedTools`:** the list now restricts the resident's tools. Earlier versions ignored it with a startup warning, so the resident had every tool. Before upgrading, check that the list names every tool the resident uses, with `utils` and each utility's own name (`module--name`) for the utilities it runs, or remove the field to keep every tool. Unchanged: a recipe without `agent.allowedTools` keeps every tool, as before.
